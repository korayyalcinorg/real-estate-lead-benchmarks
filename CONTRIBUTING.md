# Contributing

Contributions are welcome when they improve measurement quality, reproducibility or practical usefulness.

## Good contribution types

- clearer KPI definitions
- additional segmentation methods
- benchmark calculation improvements
- privacy-safe example datasets
- validation rules
- reporting templates
- documentation corrections

## Benchmark claims

Do not add unsupported statements such as "the industry average is X%" without a traceable source and compatible methodology.

Any empirical benchmark contribution should include:

- sample size
- date range
- geography
- lead sources
- inclusion/exclusion rules
- KPI formula
- known limitations

## Data privacy

Never submit customer PII, including:

- names
- phone numbers
- e-mail addresses
- private messages
- CRM IDs that can identify a person
- addresses tied to an identifiable customer

Use synthetic, aggregated or irreversibly anonymized data.

## Metric naming

Always state denominators. For example, distinguish:

- appointment rate among contacted leads
- appointment rate among qualified leads
- lead-to-sale conversion
- contact-to-sale conversion

## Suggested workflow

1. Open an issue describing the proposed change.
2. Keep changes focused and documented.
3. Update the methodology or data dictionary if a metric definition changes.
4. Include a small reproducible example when adding calculations.
